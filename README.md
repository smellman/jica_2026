# JICA Seminar 2026

## How to create seminar materials by hand

macOS + Marp

```bash
brew install node
npx @marp-team/marp-cli@latest jica-seminar-2026.md -o jica-seminar-2026.html
npx @marp-team/marp-cli@latest jica-seminar-2026.md -o jica-seminar-2026.pdf --allow-local-files
npx @marp-team/marp-cli@latest jica-seminar-2026.md -o jica-seminar-2026.pptx --allow-local-files
```

Notes: all materials are generated by github actions.

See: https://smellman.github.io/jica_2026/
