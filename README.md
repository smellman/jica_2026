# JICA Seminar 2025

## How to create seminar materials by hand

macOS + Marp

```bash
brew install node
npx @marp-team/marp-cli@latest jica-seminar-2025.md -o jica-seminar-2025.html
npx @marp-team/marp-cli@latest jica-seminar-2025.md -o jica-seminar-2025.pdf --allow-local-files
npx @marp-team/marp-cli@latest jica-seminar-2025.md -o jica-seminar-2025.pptx --allow-local-files
```

Notes: all materials are generated by github actions.

See: https://smellman.github.io/jica_2025/
